# 車內收納大挑戰

JOWUA 的車內收納小遊戲。橫向大螢幕、觸控操作，用瀏覽器直接開啟，沒有帳號、也不用建置。

畫面是一輛通用的電動休旅車內裝（俯視、稍微傾斜），沒有真實廠牌標誌，也不會寫出車型名稱。置物格有中控台置物盤、扶手箱、左右車門置物袋、左右椅背收納袋。下方或右側的待收納列會一個一個出現雜物，拖進格子裡放下。

## 開啟

這個資料夾就是靜態網站。因為用了 ES module 與 service worker，請用靜態伺服器，不要直接用 `file://` 開。

在儲存庫根目錄：

```bash
python3 -m http.server 8080
```

然後打開：

```text
http://127.0.0.1:8080/car-storage-challenge/
```

第一次載入後，service worker 會把頁面、腳本和 Three.js 存進快取，之後可以離線再開同一個網址。

## 怎麼玩

1. 標題畫面按「開始」。
2. 看完「怎麼玩」，按「開始第 1 關」。
3. 按住待收納列的物品，拖到置物格。格子會對齊；放得下是亮色，放不下是灰色。
4. 點一下已經選中的物品，或按「旋轉」，轉 90 度。
5. 待收納列超過上限，或倒數結束，遊戲結束。
6. 過關或結束時會看到分數，以及示範碼 `JOWUA-DEMO`（畫面上標明「示範用、非正式優惠」）。「分享成績」會用系統分享；若不能分享，就改為複製文字。

聲音預設關閉，右上角可以打開。

## 改關卡、加物品

全部資料在 `js/levels.js`。

### 物品

每個物品有這些欄位：

| 欄位 | 意思 |
| --- | --- |
| `id` | 內部代號，關卡的 `spawns` 用這個 |
| `nameKey` | 名稱，對應 `js/i18n.js` |
| `emoji` | 畫在方塊上的符號 |
| `color` | 方塊顏色，請維持白、灰、黑 |
| `image` | 留空表示用 emoji。要換圖就填 `.ktx2` 路徑 |
| `thickness` | 3D 方塊的高度 |
| `points` | 放進去的分數 |
| `shape` | 佔用的格子，`[0, 0]` 是左上，x 向右、y 向下 |

新增物品時，先在 `ITEMS` 加一筆，再在 `js/i18n.js` 的 `zh-Hant` 加上 `item.你的代號`。`en`、`fr`、`ja`、`ko` 先留空，之後補上即可，沒翻到的字會回到繁體中文。

形狀範例：直的三格水壺是 `[[0, 0], [0, 1], [0, 2]]`。

### 關卡

`LEVELS` 有三關。每一關：

| 欄位 | 意思 |
| --- | --- |
| `time` | 倒數秒數 |
| `spawnEvery` | 每隔幾秒出現下一個物品（第一個一開始就出現） |
| `trayLimit` | 待收納列上限，再出現一個就結束 |
| `tidyBonus` | 靠著邊緣或其他物品的加分 |
| `fullBonus` | 某個置物格塞滿的加分（每格只算一次） |
| `timeBonusPerSec` | 過關時，剩下的每一秒加多少分 |
| `compartments` | 這一關的置物格 |
| `spawns` | 物品出現順序，內容是 `ITEMS` 的 id |

置物格：

| 欄位 | 意思 |
| --- | --- |
| `cols`, `rows` | 寬和高，以格子計 |
| `ox`, `oz` | 第 (0, 0) 格的角落。x 向右，z 向車尾 |
| `y` | 格面高度 |
| `cell` | 一格的邊長，目前是 `1` |
| `mask` | 可省略。`1` 可以放，`0` 是堵住的。第 0 列靠近車頭 |

格子不要互相重疊，而且物品的總格數不要超過可放的格子，否則那一關會放不完。

## 把藝術換成圖片

預設是色塊加 emoji，不附任何圖片檔，所以沒有授權不清楚的素材。

若要換成自己的圖：

1. 把貼圖做成 **KTX2**（Basis Universal）。不要把未授權的 PNG、字型或商標放進專案。
2. 在物品上設定 `image: "assets/phone.ktx2"`。`emoji` 會留作載入失敗時的備援。
3. Three.js 的 KTX2 解碼器要放在 `vendor/basis/`（`KTX2Loader.js` 與 Basis transcoder）。遊戲會在需要時才載入；沒有這些檔案就繼續用 emoji。

色塊顏色改 `color`。介面強調色只有一個，在 `css/style.css` 的 `--accent`，以及 3D 預覽用的同一種亮色。

若以後改用 glTF / GLB 模型，請用 Draco 或 meshopt 壓縮，貼圖用 KTX2。目前的車內與物品是程式產生的低面數方塊，沒有模型檔：靜態車體合併成少數網格，重複的格子、物品方塊和出風口用 instancing。

## 3D 與效能

- Three.js r170（MIT，見 `vendor/three.LICENSE`），由 service worker 一併快取。
- 沒有 WebGL 時改畫 2D canvas，玩法相同。
- 裝置像素比限制在 1 到 1.5（預設最高 1.25）。若幀率掉下去，會再降低像素比，並關掉接觸陰影和多餘的光。
- 燈光只有半球光加一盞方向光，沒有即時陰影。
- 放下物品時只用很短的自訂彈簧，沒有物理引擎。
- 沒有操作、也沒有落下動畫時，不會一直重繪。

## 語言

玩家看得到的句子都在 `js/i18n.js` 的 `STRINGS`。現在使用 `zh-Hant`。

## 測試

邏輯測試：

```bash
node --test car-storage-challenge/tests/puzzle.test.mjs
```

瀏覽器測試（需本機已安裝 Playwright 與 Chrome）會用觸控模擬，在 1920×1200 與 1280×800 檢查拖放、旋轉、放不下、過關、失敗和分享：

```bash
node car-storage-challenge/tests/e2e.mjs
```
