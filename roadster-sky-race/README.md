# 天空飛馳 Sky Roadster

純前端 HTML5 + Three.js 的賽車遊戲：從 **15 款原創造型的電動車**（Roadster 系列、Model 系列含 Performance／Plaid／L、Cybertruck／Cyberbeast、Semi、Cybercab、Robovan）中選一台，在三條賽道上高速飆馳，遇到斷橋缺口時啟動火箭推進器飛越，並撿取能量環補充能量。

- 主要設計給 **Tesla 車機瀏覽器**（Chromium、1920×1200 橫向觸控螢幕）搭配 **JOWUA 搖桿**（藍牙或 USB 接收器）遊玩。
- 觸控按鍵與鍵盤只是備用。
- 沒有後端、沒有建置步驟，所有檔案放到任何靜態網站（例如 GitHub Pages）就能玩。
- 全部美術為原創程序生成（Three.js 幾何 + canvas 貼圖），**沒有使用任何 Tesla 商標、車標、「T」字樣、文字或官方模型資料**，屬於致敬風格的粉絲作品。
- 預設車輛（新 Roadster 風格）的比例靈感來自新一代電動跑車：極低、寬體的雙座硬頂／targa 跑車，長而漸縮的車鼻、短車尾、寬大的後肩線、細長水平 LED 前後燈條、深色玻璃車頂、空力輪圈與低扁平比輪胎、後擴散器，以及（SpaceX 套件風格的）冷氣火箭推進噴口。車身為放樣截面生成的光滑曲面，不是方塊拼成。

> 🅿️ **僅限停車（P 檔）時遊玩。** Tesla 車機瀏覽器只允許在停妥時使用網頁遊戲，行駛中請勿操作。

## 在電腦上執行（測試）

```bash
cd roadster-sky-race
python3 -m http.server 8000
# 瀏覽器開啟 http://localhost:8000/
```

> 必須透過 HTTP 伺服器開啟（不能直接雙擊 index.html），因為使用 ES 模組。Three.js 已放在 `vendor/`，不需要網路。

網址參數（除錯用）：`?q=low|med|high` 指定畫質、`?autostart=1&nocount=1` 直接開始、`?noadapt=1` 關閉動態解析度。

## 操作

預設針對 **JOWUA 搖桿的 Switch（S）模式**（Nintendo Switch Pro Controller 配置）調校；偵測到 Xbox／X-input 搖桿時，標示自動換成 Xbox 名稱（按鈕位置相同：下方實體鍵＝標準索引 0）。

| 動作 | 搖桿（Switch 標示） | 搖桿（Xbox 標示） | 鍵盤 | 觸控 |
|---|---|---|---|---|
| 轉向 | 左搖桿左右（十字鍵也可） | 同左 | ← → / A D | ◀ ▶ |
| 加速 | ZR | RT | ↑ / W | 加速 |
| 煞車／倒車 | ZL | LT | ↓ / S | 煞車 |
| 起飛推進器（按住） | B（下） | A | 空白鍵 | 推進起飛 |
| 氮氣 | A（右） | B | Shift | 氮氣 |
| 空中升降 | 左搖桿上下 | 同左 | Q / E | — |
| 切換視角 | Y（左） | X | C | 視角 |
| 回到賽道 | X（上） | Y | R | 回賽道 |
| 暫停選單 | ＋ | Start | Esc / P | 暫停 |

- **推進器**：按住推進鍵（Switch 的 B／Xbox 的 A）會把車抬到懸停高度（左搖桿上下可調高度），消耗推進能量；空中左右可轉向。放開就落下並有懸吊與震動回饋。
- **氮氣**：消耗同一條能量，直線加速。
- **能量環**：地面與缺口上空都有；穿過去 +30 能量並獲得加速。
- 掉進峽谷會自動回到跳台前。每圈需依序經過三個檢查點才算一圈；最佳圈速存在瀏覽器 localStorage。
- 選單也可用搖桿操作：十字鍵／左搖桿移動，**A 確認、B 返回**（兩種設定檔都是標示為 A／B 的按鍵；Switch 設定檔的 A 在右側、B 在下方，Xbox 設定檔的 A 在下方、B 在右側，與各自手把上的印字一致）。

## 搖桿與按鍵設定

- 使用瀏覽器標準 Gamepad API，支援兩種**設定檔**：**Switch Pro**（裝置名稱含 `Pro Controller`／`Switch`／`Nintendo` 或廠商 ID `057e`）與 **Xbox**（`Xbox`／`045e`），其餘當作通用（Xbox 標示）。設定檔決定按鈕標示、確認／返回鍵、以及板機處理方式。
- **搖桿模式（手動覆寫）**：JOWUA 搖桿在 S 模式與 X（Xbox/X-input）模式會回報不同的裝置 id。若自動偵測不準，到 **畫質與設定** 或 **按鍵設定** 畫面選 **「自動偵測 / Switch 模式 / X-input（Xbox）模式」**（搖桿可操作）。預設為「自動偵測」；選了 Switch／X-input 會強制使用該設定檔（按鈕標示、板機數位/類比處理、確認返回鍵），並存在 localStorage（`skyroadster.padmode`）。`gamepad-test.html` 也有同樣的下拉選單（與遊戲共用設定），並顯示目前使用的設定檔與是否為手動指定。
- **板機**：Switch Pro 的 ZL/ZR 是**數位**按鈕（只有 0 或 1），遊戲會把油門／煞車做斜坡平滑（不會瞬間全油門）；Xbox 的 LT/RT 是類比，直接使用。
- **非標準映射**（`mapping === ''`，Pro Controller 有時會這樣）：十字鍵可能是 hat 軸（例如 axes[9]，靜止值約 1.2857）；遊戲會自動偵測「靜止時不在 0」的軸並**忽略**，忽略 NaN／±1.2857 這類值，連線時校正搖桿中心，套用放射狀死區（約 0.15）與響應曲線，**絕不讓未歸零的軸去轉向**。
- **漂移修正**：搖桿若靜止時偏離中心，會緩慢自動歸中；按鍵設定畫面有 **「校正搖桿」** 按鈕可立即重新取樣中心（請放開搖桿）。
- 藍牙、USB 接收器或不同 JOWUA 模式的按鍵編號可能不同：到 **按鍵設定** 畫面，點一個動作後依提示操作搖桿即可重新指定（支援按鈕或軸；板機若是軸也能自動辨識），設定存在 localStorage。**重設為標準** 可還原。
- 震動使用 `gamepad.vibrationActuator.playEffect('dual-rumble')`；不支援時自動略過。可在設定關閉。
- **gamepad-test.html**：先到這頁確認搖桿被偵測、顯示偵測的設定檔、按鍵編號與原始軸數值（靜止非 0 的軸會標示為忽略），並可截圖或複製 JSON 摘要（裝置 id、mapping、設定檔、hat 軸、各軸靜止值、曾按過的按鈕、軸範圍），方便回報給開發者。

## 轉向左右反轉
「畫質與設定」有「轉向左右反轉」（預設關）。開啟後方向鍵／WASD／搖桿／十字鍵／觸控按鈕的左右全部對調（選單導覽不變）；設定存在瀏覽器（localStorage），`gamepad-test.html` 也能查看與切換。若覺得按右會向左轉，請先重新整理頁面取得最新版；仍反向的話打開此選項。

## 賽道
三條賽道可在主選單「選擇賽道」切換（鍵盤／搖桿可導覽，選擇會記住）：
1. **峽谷沙漠** — 日間沙漠峽谷（原有賽道）
2. **海岸懸崖** — 日落海岸城市懸崖，含橋樑與隧道、海上飛躍
3. **雪山夜道** — 夜間阿爾卑斯山道，髮夾彎與山谷飛躍

每條賽道有獨立光線／天空／霧效、小地圖與最佳單圈紀錄（`skyroadster.best.<賽道id>`）。

## 車輛（15 款）

開始畫面的 **「選擇車輛」**（搖桿十字鍵／左搖桿選擇、確認鍵選取，或直接點選）可從 15 款車中挑選（列表可捲動）；選擇與各車車色會即時預覽，並存在 localStorage（`skyroadster.vehicle`、`skyroadster.paint.<車種>`）。選單內顯示 速度／加速／操控／飛行（另有堅固）屬性條，由各車的物理調校數值推導。

| 車款 | 造型重點（原創程序生成） | 特性 |
|---|---|---|
| 新 Roadster（預設） | 低矮寬體雙座跑車 | 最快、最靈活、飛行最佳 |
| Model 3 | 四門轎車，尖鼻與獨立行李箱蓋 | 輕巧均衡、入門 |
| Model Y | 較高的掀背休旅 | 穩定、續航佳 |
| Model S | 長軸距低趴掀背 | 加速強、極速高 |
| Model X | 大型高頂休旅（鷹翼門簡化為一般車門） | 較重、堅固、飛行吃力 |
| Cybertruck | 稜面折線車身、尖鼻、單斜線車頂與貨斗（稜面放樣） | 很重、很耐撞、飛得低；只有拉絲不鏽鋼色 |
| Semi | 卡車頭＋短拖車，10 個輪子 | 最重、最慢、最堅固、能量最多，只能低空短飛 |
| Cybercab | 小巧圓潤雙座，沒有方向盤與後視鏡 | 轉向最靈活、輕盈好飛、較不耐撞 |
| 2008 Roadster | 初代經典雙座敞篷風格 | 輕巧靈活、飛行輕盈 |
| Model 3 Performance | Model 3＋尾翼 | 更強加速與抓地 |
| Model Y L | 加長六座休旅 | 較重、續航與堅固提升 |
| Model S Plaid | 三馬達旗艦＋尾翼 | 加速與極速頂尖 |
| Model X Plaid | 三馬達休旅＋尾翼 | 休旅身形、加速兇猛 |
| Cyberbeast | Cybertruck 三馬達版 | 加速更猛、更耐撞 |
| Robovan | 低矮修長無人廂型車 | 穩定、續航長、轉向偏鈍 |

- 每台車有自己的物理調校（質量、極速、加速、抓地、轉向、推進器能量、升力、爬升、最大懸停高度、氮氣、堅固度）；**所有車都能使用推進器**，重車的懸停高度與升力較低、耗能較高，但撞護欄與落地的速度損失較小。數值在 `js/vehicles.js`。
- 全部造型為**原創幾何**，沒有任何標誌、徽章、文字或官方模型資料；名稱只用在選單標示，模型上沒有。
- 面數：低畫質（LOD 低）每車 6~13k 三角形，中／高畫質每車 11~23k（< 27k 預算）；材質、貼圖與空力輪圈貼圖共用，靜態零件依材質合併，每車約 30 個網格。

## 車色

在 **選擇車輛** 畫面選車色：每車都有 **銀灰、午夜藍、烈焰紅、珍珠白、曜石黑**；**Cybertruck／Cyberbeast 只有拉絲不鏽鋼**。皆為金屬車漆 + 清漆層（低畫質為一般 PBR 金屬漆），每款車記住自己的車色（localStorage）。

## 畫質

設定中可選 **低 / 中 / 高**（切換會重新載入）：

| | 解析度 | 陰影 | 地形 | 岩石 |
|---|---|---|---|---|
| 低 | 62% | 無（改用假陰影） | 20 m 網格 | 90 |
| 中（預設） | 85% | 1024 | 13 m | 240 |
| 高 | 100% | 2048 | 9 m | 320 |

車輛模型有兩種細節等級：**低**畫質用低面數車身（每車約 6~13k 三角形、標準 PBR 材質），**中／高**用完整車身（每車約 11~23k 三角形，Physical 清漆車漆與玻璃）。

CPU 核心數 ≤ 4 的裝置第一次會自動選「低」。遊戲另有動態解析度：幀率過低時自動降低渲染解析度。每幀約 45 次繪製呼叫。

## 部署到 GitHub Pages（帳號 hgsteven-debug）

專案目前**尚未推送**。要上線時：

```bash
cd roadster-sky-race
git remote add origin https://github.com/hgsteven-debug/sky-roadster.git   # 先在 GitHub 建立空的 repo
git branch -M main
git push -u origin main
```

接著到 GitHub repo →「Settings」→「Pages」→ Source 選 `Deploy from a branch`，Branch 選 `main` / `/ (root)`。幾分鐘後網址為
`https://hgsteven-debug.github.io/sky-roadster/`，在車機瀏覽器輸入即可（建議加入書籤）。所有路徑皆為相對路徑，放在子目錄也能運作。

## 專案結構

```
index.html            遊戲入口（含 UI 結構）
gamepad-test.html     搖桿測試頁（獨立、無依賴）
css/style.css
js/main.js            主迴圈、狀態機、圈速、相機
js/physics.js         車輛物理（地面抓地/漂移、推進器飛行、護欄、落地）
js/tracks.js          三條賽道定義與主題（光線／地形）
js/track.js           賽道樣條、傾斜、缺口、地面高度查詢
js/world.js           天空、光線、地形、道路、護欄、岩石、能量環
js/car.js             程序生成的 15 款車輛模型（放樣車身、稜面放樣、車輪拱、燈條、噴口、空力輪圈）
js/vehicles.js        車輛資料：名稱、車漆、各車物理調校、屬性條推導
js/input.js           Gamepad / 鍵盤 / 觸控、設定檔（Switch/Xbox，自動或手動）、校正、按鍵對應、震動
js/ui.js, hud.js, audio.js, textures.js, util.js
vendor/               three.module.min.js (r160, MIT)
tests/                無頭 Chrome 測試腳本（puppeteer-core，見 tests/README.md）
```
